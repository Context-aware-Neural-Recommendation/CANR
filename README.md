# Context-Aware Neural Recommendation Engine

A Deep Learning recommendation system designed for an e-commerce or
content-streaming platform.

## Project Objective

Build a context-aware recommendation engine using a Two-Tower Neural
Network that uses user metadata, historical interactions, and item context
to generate personalized recommendations.

## Dataset

H&M Personalized Fashion Recommendations Dataset.

## Technology Stack

- Python
- TensorFlow / Keras
- TensorFlow Recommenders (TFRS)
- PySpark
- Apache Airflow
- Redis
- FastAPI
